# 0149 — 설정과 업데이트 확인을 Mac 앱 이름 메뉴에 두고, ⌘,·Ctrl+,로 설정을 연다(워드 탭 빼고)

## 맥락

2026-11-15 Mac(0.12.12) 사용자 의견: "도움말에 업데이트 버튼이 없다", "Mac에서는 보통 ⌘,로 설정을 여는데 안 먹고, 설정을 어디서 하는지 모르겠다."

코드로 확인한 것:

- 0.12.12의 Mac 메뉴 막대에는 모든 탭에 **도움말 ▸ 업데이트 확인…**이 있었다. 그러나 앱 이름 메뉴는 Electron의 맨 `role: 'appMenu'`라 정보·서비스·가리기·종료뿐이었다. 그 메뉴의 "정보" 창도 Electron 기본 창이라 업데이트 버튼이 없었다. Mac 사용자가 업데이트와 설정을 찾는 곳이 바로 이 메뉴다.
- ⌘,는 어디에도 묶여 있지 않았다. 설정을 여는 길은 홈 왼쪽 아래 칸 하나뿐이어서, 문서 탭에서는 메뉴로 설정에 갈 수 없었다. Windows·Linux도 마찬가지였다.
- 워드 탭은 ⌘,·Ctrl+,를 이미 **아래 첨자**로 쓴다. Word의 ⌘=가 확대 키와 겹쳐 옮긴 것이고, 도움말 단축키 표에도 적혀 있다.

## 결정

- **Mac 앱 이름 메뉴를 직접 만든다.** 순서는 이음오피스 정보(버전 창, 업데이트 단추 있음) → 업데이트 확인… → 설정… → 서비스 → 가리기 → 종료다(`macAppMenuTemplate`, `packages/electron-utils/src/app-menu.ts`). 모든 탭의 메뉴를 만드는 곳(껍데기의 8개, 워드·엑셀·파워포인트)이 이것을 쓴다. 도움말 ▸ 업데이트 확인…은 그대로 둔다.
- **"설정…"은 홈의 설정을 일반 절로 연다.** 껍데기 창을 앞으로 가져오고 홈 탭으로 옮긴 뒤 연다(`openHomeSettings`). 떼어 낸 창에서 눌러도 같다.
- **⌘,(Mac)와 Ctrl+,(Windows·Linux)가 설정을 연다.** Mac에서는 메뉴의 단축키로, Windows·Linux에서는 껍데기의 키 처리(`tab-shortcuts.ts`)로 받는다. Windows·Linux의 ☰ 팝업에도 업데이트 확인… 위에 설정…(Ctrl+,)을 넣는다.
- **워드 탭에서는 이 키가 아래 첨자로 남는다.** 워드 탭의 메뉴와 ☰ 팝업에는 "설정…"을 단축키 표시 없이 두고, 키도 가로채지 않는다. 워드 자체의 "기본 설정…"(단위)은 Mac 앱 이름 메뉴의 설정… 바로 아래에 그대로 있다.

## 택하지 않은 것

- **워드 탭에서도 ⌘,를 설정으로 바꾸고 아래 첨자를 다른 키로 옮기기.** Mac 관례에는 더 맞지만, 도움말에 적어 둔 아래 첨자 키를 쓰던 사람의 손버릇을 깬다. 아래 첨자의 원래 Word 키(⌘=)는 확대와 겹쳐서 옮길 곳도 마땅치 않다.
- **설정을 도움말 메뉴에 넣기.** 신고자는 도움말 메뉴를 보고도 업데이트 확인을 찾지 못했다. Mac 사용자가 찾는 자리는 앱 이름 메뉴다.

## 결과

- Mac에서는 앱 이름 메뉴에서 업데이트 확인과 설정을 찾을 수 있다. 워드 탭이 아니면 ⌘,로도 설정이 열린다.
- 도움말 "설정, 언어, 테마와 MCP 연동", "설치와 업데이트", "키보드 단축키"를 22개 언어로 고쳤다.
- Mac 실기기에서는 확인하지 못했다. 메뉴 모양과 ⌘,는 사용자 보고로 확인한다.
- draw.io(다이어그램 탭)에 Ctrl+, 단축키가 있는지는 이 PC에 draw.io 묶음이 없어 확인하지 못했다. 있다면 Windows·Linux의 다이어그램 탭에서는 껍데기가 먼저 받는다.
