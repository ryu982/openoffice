# 0148 — OpenRouter 무료 연결의 선택기는 OpenRouter가 새로 내놓은 무료 모델도 보인다

결정 0138(무료 연결의 선택기는 남아 있는 시험된 모델만 보인다)의 선택기 부분을 바꾼다. 옮기기(`openRouterFreeModelFor`)는 그대로다.

## 맥락

무료 연결의 선택기는 `OPENROUTER_FREE_MODELS`(앱에서 두 요청을 해낸 모델)만 보였다. 키로 받은 OpenRouter 목록에는 새로 나온 `:free` 모델(예: `particle-ai/particle-1:free`)이 들어 있어도 선택기에는 나오지 않았다. 새 모델을 쓰려면 시험을 거쳐 목록에 넣고 새 버전을 낼 때까지 기다리거나 고급에서 이름을 직접 쳐야 했다. 무료 모델은 자주 생기고 사라져서, 고정 목록만으로는 사람이 쓸 수 있는 모델이 늘 뒤처진다.

받은 목록은 이미 걸러져 있다. 대화 모델만(이름 거르기 `NOT_CHAT`), 도구 호출을 지원하는 것만(`supported_parameters`에 `tools`, `servesChat`) 남는다(결정 0087, `key-models.ts`).

## 결정

- **선택기는 시험된 모델을 먼저, 그 뒤에 받은 목록의 다른 무료 모델을 보인다.** 시험된 모델의 차례와 좁히기는 결정 0138 그대로다. 그 뒤에 받은 목록에서 이름이 `:free`로 끝나고 시험된 목록에 없는 모델을 받은 목록의 차례(최신순)로 붙인다.
- **`:free`가 아닌 모델은 여전히 넣지 않는다.** 무료 연결이 유료 모델로 가지 않게 하는 장치는 그대로다(`docs/security.md`).
- **시험에서 떨어진 모델은 넣지 않는다.** `tools/free-models-rejected.json`의 모델은 앱에서 멈추거나 거절당한 것으로 확인됐다. 앱은 그 이름을 `OPENROUTER_REJECTED_FREE_MODELS`(`free-ai.ts`)로 갖고, 단위 시험이 두 목록이 같은지 본다. 시험 도구는 지금처럼 JSON에 적고, 시험이 실패하면 같은 이름을 상수에도 넣는다.
- **앱이 고르는 일은 바뀌지 않는다.** 새로 연결할 때의 기본 모델과, 사라진 모델에서 옮겨 가는 곳은 시험된 모델뿐이다. 시험하지 않은 모델은 사람이 선택기에서 골랐을 때만 쓰인다.

## 택하지 않은 것

- **지금처럼 시험된 모델만 보이기.** 결정 0138의 까닭(도구 호출을 지원한다고 나온 모델도 앱에서 멈추거나 거절당한다)은 여전히 맞다. 그러나 그 위험은 사람이 직접 고른 모델에만 생기고, 실패하면 다른 모델로 바꾸면 된다. 요금이 나가는 위험은 없다. 쓸 수 있는 새 모델을 감추는 손해가 더 크다고 봤다.
- **시험하지 않은 모델을 따로 묶어 "시험 안 됨"으로 표시하기.** 선택기는 제공자마다 모델 이름 목록 하나를 받는다. 표시를 더하려면 22개 언어 문구와 선택기 구조를 바꿔야 한다. 시험된 모델이 앞에 오는 차례로 먼저 낸다.
- **떨어진 모델 목록을 앱이 JSON에서 직접 읽기.** `tools/`는 앱 꾸러미에 들어가지 않고, 브라우저 쪽 코드가 저장소 밖 파일에 기대게 된다.
- **새 모델로 옮기기나 기본 모델 삼기.** 시험하지 않은 모델을 앱이 대신 고르지 않는다(결정 0138).

## 결과

- 코드: `packages/ai-provider/src/free-ai.ts`(`keyProviderModels`, `OPENROUTER_REJECTED_FREE_MODELS`).
- 시험: `packages/ai-provider/tests/free-ai.test.ts`(새 무료 모델이 시험된 모델 뒤에 최신순으로 붙는지, 유료 모델과 `:free`로 끝나지 않는 이름은 빠지는지, 떨어진 모델은 빠지는지, 떨어진 모델 목록이 JSON과 같은지, 다른 키 제공자는 받은 목록을 추천 목록 뒤에 붙이는지).
- 고친 문서: `docs/business-rules.md`("무료 연결"), `docs/operations.md`("무료 모델 점검"), `packages/ai-provider/AGENTS.md`, 결정 0138에 이 결정을 가리키는 줄.
- 한계. 시험하지 않은 모델을 고른 사람은 그 모델이 앱의 도구 반복을 끝내지 못하면 멈춤이나 거절을 본다. 선택기에서 다른 모델로 바꾸면 된다. 목록을 아직 받지 못한 앱(켠 직후 첫 응답 전)은 전처럼 시험된 모델만 보인다.
- 앱 화면으로는 확인하지 않았다. 단위 시험만 했다.
