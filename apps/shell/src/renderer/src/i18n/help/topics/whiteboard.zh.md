# 白板：头脑风暴、手绘与批注

白板编辑器会在标签页中打开 `.whiteboard` 文件。你可以在无限自由画板或固定页面上排列便签、文本、形状、连线、表格、贴纸、图片、链接卡片和压感手绘笔迹，将 PDF 页面导入为背景，导出为图片或 PDF，并与 AI 面板协作。所有操作均在你的电脑本地完成。

## 打开与新建

- 从主页的**白板**磁贴或文件菜单中的新建开始，会打开一块空白的无限自由画板。
- 可通过打开对话框、拖入窗口、最近文件、文件夹树、快速预览（空格）或 Google 云端硬盘打开 `.whiteboard` 文件。在 Windows 上安装 GenOffice 后会自动注册为 `.whiteboard` 的默认程序。
- Excalidraw 文件（`.excalidraw`、`.excalidraw.png`、`.excalidraw.svg`）会导入为新的无标题白板。原文件绝不会被覆盖，未编辑直接关闭不会提示保存，首次保存默认建议同目录下的 `.whiteboard` 文件。网页嵌入等不支持的元素会跳过并在提示条显示数量。在 Windows 上 `.excalidraw` 仅出现在“打开方式”列表中。
- 若该白板已打开，再次打开会直接切到对应标签页。

## 编辑与工具

- 同一个 `.whiteboard` 文件可在页面栏中混用自由画板与固定页面（16:9 屏幕、A4 竖向/横向以及自定义 PDF 页面尺寸）。
- 提供选择、便签、富文本、八种形状、连线与箭头、压感画笔/荧光笔/橡皮擦、图片、表格、内置贴纸与链接卡片工具。
- 将 `.pdf` 文件拖到已打开的白板中，或选择**导入 PDF**，即可把选中的 PDF 页面转为固定背景页，方便在其上手绘和贴便签。从主页或文件菜单打开 `.pdf` 仍会使用 PDF 编辑器打开。
- 按 F5 或点击**演示**可进入全屏演示模式，使用方向键翻页。
- 在深色主题下，仅工具栏、面板与页面外背景变深，纸张、便签、形状与笔迹仍保持文档原本颜色。

## 保存、导出与打印

- 保存、另存为、自动保存、崩溃恢复副本及分屏保存冲突检测与其他编辑器一致。无改动时不会重写文件。
- 支持将**全部页面**或**仅当前页**导出为 PNG、SVG 或 PDF。自由画板会按所有对象的外接区域加边距导出与打印，空画板则使用默认起始区域。
- 打印（Ctrl+P）支持常规打印与高级多页排版。浅色与深色主题下的导出与打印结果完全一致。

## AI 面板

- 可让 AI 整理便签、按研讨会或复盘模板排版、添加形状/连线/表格/图片或总结白板内容。
- AI 会接收白板的结构化文本表；当所选模型支持图像输入时，还会自动附上当前页的图片。纯文本模型仅使用文本表运行。
- 每次 AI 编辑调用对应一步撤销（Ctrl+Z），仅在屏幕上高亮改动对象而不影响保存文件，并在回复卡片下提供**撤销这些更改**。
- `.whiteboard` 文件也可在其他编辑器的 AI 面板中作为附件或通过 `@` 引用、在主页搜索、用于**由当前文档生成其他文档**（含免 AI 转为 Markdown），并支持[终端命令](help://cli)（`ieumoffice whiteboard read`、`ieumoffice whiteboard apply`、`ieumoffice create --type whiteboard`）。

## 网络使用与链接卡片

- 打开、编辑、导出、打印以及导入 Excalidraw 或 PDF 页面均不会向互联网发送任何请求。
- 点击链接卡片会在默认浏览器中打开 `http`、`https` 或 `mailto` 地址。
- 仅当你在添加或编辑链接卡片时主动开启**获取标题与预览图**，GenOffice 才会向该页面发起一次连接并将预览图保存在 `.whiteboard` 文件内部。
