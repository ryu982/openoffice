# 화이트보드: 아이디어 정리, 필기와 주석

화이트보드 편집기는 `.whiteboard` 파일을 탭에서 엽니다. 무한 자유형 보드나 고정 페이지 위에 포스트잇, 글, 도형, 연결선, 표, 스티커, 그림, 링크 카드, 필압 펜 필기를 자유롭게 배치하고, PDF 쪽을 배경으로 깔아 주석을 달며, 그림이나 PDF로 내보내고 AI 창과 함께 작업할 수 있습니다. 모든 편집은 이 PC 안에서 이루어집니다.

## 열기와 새로 만들기

- 홈의 **화이트보드** 타일이나 파일 메뉴의 새로 만들기로 시작하면 빈 자유형 무한 보드가 열립니다.
- `.whiteboard` 파일은 열기 창, 창으로 끌어다 놓기, 최근 파일, 폴더 나무, 빠른 미리보기(스페이스바), Google 드라이브에서 열 수 있습니다. Windows에서는 GenOffice를 설치하면 `.whiteboard` 기본 프로그램으로 등록됩니다.
- Excalidraw 파일(`.excalidraw`, `.excalidraw.png`, `.excalidraw.svg`)은 제목 없는 새 화이트보드로 가져옵니다. 원본 파일은 덮어쓰지 않으며, 수정 없이 닫으면 저장을 묻지 않고 첫 저장 시 같은 폴더의 `.whiteboard` 파일을 제안합니다. 웹 임베드 등 지원하지 않는 요소는 건너뛰고 개수를 알림 띠로 알려 줍니다. Windows에서 `.excalidraw`는 "연결 프로그램" 후보에만 등록됩니다.
- 이미 열려 있는 화이트보드 파일을 다시 열면 그 탭이 앞으로 나옵니다.

## 편집과 도구

- 하나의 `.whiteboard` 파일 안에서 페이지마다 자유형 보드와 고정 페이지(16:9 화면, A4 세로·가로, PDF 쪽 맞춤 크기)를 섞어 쓸 수 있습니다.
- 선택, 포스트잇, 서식 있는 텍스트, 도형 8종, 연결선·화살표, 필압 펜·형광펜·지우개, 이미지, 표, 내장 스티커, 링크 카드 도구를 제공합니다.
- 여러 개체를 한꺼번에 고르려면 선택 도구로 빈 곳에서 끌어 사각형을 그립니다. 개체가 빽빽해 빈 곳이 없으면 왼쪽 도구 막대에서 **영역 선택**(M)을 고르고 개체 위에서부터 끌어도 됩니다. 사각형 안에 온전히 들어간 개체만 선택됩니다. Shift(또는 Ctrl)를 누른 채 개체를 누르면 선택에 더하거나 빼고, Shift를 누른 채 끌면 다른 사각형 안의 개체를 더하며, Ctrl+A(Mac은 ⌘A)는 지금 페이지의 개체를 모두 고릅니다. 고른 개체 중 하나를 끌면 모두 함께 움직이고, 맨 앞으로·맨 뒤로·복제·삭제도 고른 개체 모두에 한 번에 적용되며 각각 실행 취소 1단계입니다.
- 열려 있는 화이트보드 위로 `.pdf` 파일을 끌어다 놓거나 **PDF 가져오기**를 고르면, 선택한 PDF 쪽마다 고정 크기 배경 페이지가 추가되어 그 위에 포스트잇과 필기를 얹을 수 있습니다. 홈이나 파일 메뉴에서 `.pdf`를 열면 기존처럼 PDF 편집기에서 열립니다.
- F5 키나 **발표** 단추를 누르면 전체 화면 발표 모드로 전환되어 방향키로 페이지를 넘길 수 있습니다.
- 어두운 테마에서는 도구 막대, 패널, 보드 바깥 바탕만 어두워지고, 보드 종이와 포스트잇·도형·필기 색은 원본 그대로 유지됩니다.

## 저장, 내보내기와 인쇄

- 저장, 다른 이름으로 저장, 자동 저장, 복구 사본, 화면 나누기 저장 충돌 확인은 다른 편집기와 같습니다. 바뀐 내용이 없으면 파일을 다시 쓰지 않습니다.
- **모든 쪽** 또는 **지금 쪽만** 골라 PNG, SVG, PDF로 내보낼 수 있습니다. 자유형 보드는 전체 개체 영역(여백 포함)에 맞춰 출력되며, 비어 있으면 기본 시작 구역을 기준으로 합니다.
- 인쇄(Ctrl+P)는 기본 인쇄와 고급 인쇄 배치를 모두 지원합니다. 내보내기와 인쇄 결과는 밝은 테마와 어두운 테마에서 똑같습니다.

## AI 창

- AI에게 포스트잇 정리, 회고·워크숍 템플릿 배치, 도형·연결선·표·그림 추가, 보드 내용 요약을 부탁할 수 있습니다.
- AI에는 보드의 구조화 텍스트 표가 전달되며, 선택한 모델이 그림 입력을 지원하면 현재 페이지 그림도 자동으로 함께 전달됩니다. 글 전용 모델에서는 텍스트 표만으로 동작합니다.
- AI의 편집 호출 1회는 실행 취소(Ctrl+Z) 1단계로 묶이며, 바뀐 개체는 화면에만 강조 표시되고 답 아래 카드의 **되돌리기**로 차례 전체를 되돌릴 수 있습니다.
- `.whiteboard` 파일은 다른 편집기 AI 창 첨부, `@` 멘션, 홈 파일 검색, **이 문서로 다른 문서 만들기**(AI 없이 마크다운으로 변환 포함), [터미널 명령어](help://cli)(`ieumoffice whiteboard read`, `ieumoffice whiteboard apply`, `ieumoffice create --type whiteboard`)에서도 다룰 수 있습니다.

## 인터넷 사용과 링크 카드

- 화이트보드 열기, 편집, 내보내기, 인쇄, Excalidraw 가져오기, PDF 페이지 가져오기는 인터넷으로 아무 요청도 보내지 않습니다.
- 링크 카드를 누르면 `http`, `https`, `mailto` 주소가 기본 브라우저에서 열립니다.
- 링크 카드를 추가하거나 고칠 때 **미리보기 그림과 제목 가져오기**를 직접 켠 경우에만 해당 페이지에 한 번 접속해 제목과 대표 이미지를 `.whiteboard` 파일 안에 저장합니다.
