# ホワイトボード：アイデア整理・手書き・注釈

ホワイトボードエディターは `.whiteboard` ファイルをタブで開きます。無限のフリーボードや固定ページ上に付箋、テキスト、図形、コネクタ、表、ステッカー、画像、リンクカード、筆圧対応ペンを配置し、PDFページを背景として取り込んで書き込み、画像やPDFとして書き出し、AIパネルと一緒に作業できます。すべてお使いのPC内で完結します。

## 開く・新規作成

- ホームの**ホワイトボード**タイルやファイルメニューの新規作成から始めると、空のフリーボードが開きます。
- `.whiteboard` ファイルは開くダイアログ、ウィンドウへのドラッグ＆ドロップ、最近のファイル、フォルダーツリー、クイックプレビュー（Space）、Googleドライブから開けます。WindowsではGenOfficeのインストール時に `.whiteboard` の既定アプリとして登録されます。
- Excalidrawファイル（`.excalidraw`、`.excalidraw.png`、`.excalidraw.svg`）は無題の新しいホワイトボードとして取り込みます。元のファイルは上書きせず、未編集のまま閉じても保存確認は出ず、最初の保存で同じフォルダーに `.whiteboard` を提案します。Web埋め込みなど非対応要素はスキップされ件数が通知されます。Windowsでは `.excalidraw` は「プログラムから開く」のみに登録されます。
- すでに開いているホワイトボードを再度開くと、そのタブが前面に表示されます。

## 編集とツール

- 1つの `.whiteboard` ファイル内のページ一覧で、フリーボードと固定ページ（16:9画面、A4縦・横、PDFページに合わせたカスタムサイズ）を混在できます。
- 選択、付箋、リッチテキスト、8種類の図形、コネクタ・矢印、筆圧対応ペン・蛍光ペン・消しゴム、画像、表、内蔵ステッカー、リンクカードを備えています。
- 開いているホワイトボード上に `.pdf` ファイルをドロップするか **PDFを取り込む** を選ぶと、選択したPDFページが固定背景ページとして追加され、その上に付箋や手書きを重ねられます。ホームやファイルメニューから `.pdf` を開いた場合は従来通りPDFエディターで開きます。
- F5キーまたは **プレゼン** ボタンを押すと全画面表示になり、矢印キーでページを切り替えられます。
- ダークテーマではツールバー・パネル・ページ外の背景だけが暗くなり、用紙・付箋・図形・インクの色はドキュメント本来の色のまま保たれます。

## 保存・書き出し・印刷

- 保存、名前を付けて保存、自動保存、クラッシュ復旧コピー、分割表示での保存競合確認は他のエディターと同じです。変更がなければファイルを書き戻しません。
- **すべてのページ** または **現在のページのみ** を選んでPNG・SVG・PDFに書き出せます。フリーボードでは全オブジェクトを余白付きで収めた範囲（空の場合は既定の開始領域）で出力します。
- 印刷（Ctrl+P）は通常印刷と高度なページレイアウト印刷に対応します。書き出しと印刷の結果はライト・ダークどちらのテーマでも同一です。

## AIパネル

- 付箋の整理、ワークショップや振り返りテンプレートの作成、図形・コネクタ・表・画像の追加、ボードの要約をAIに頼めます。
- AIにはボードの構造化テキスト表が渡され、選択したモデルが画像入力に対応していれば現在ページの画像も自動で添付されます。テキスト専用モデルではテキスト表のみで動作します。
- AIの編集呼び出し1回が元に戻す（Ctrl+Z）1ステップになり、変更されたオブジェクトは画面上のみ強調表示され、回答カードの **変更を元に戻す** からまとめて戻せます。
- `.whiteboard` ファイルは他のエディターのAIパネル添付、`@` 参照、ホーム検索、**この文書から別の文書を作成**（AIを使わないMarkdown変換を含む）、[ターミナルコマンド](help://cli)（`ieumoffice whiteboard read`、`ieumoffice whiteboard apply`、`ieumoffice create --type whiteboard`）にも対応します。

## インターネット利用とリンクカード

- 開く・編集・書き出し・印刷・Excalidraw取り込み・PDF取り込みではインターネットへ一切送信しません。
- リンクカードをクリックすると `http`、`https`、`mailto` アドレスが既定のブラウザーで開きます。
- リンクカードの追加・編集時に **タイトルとプレビュー画像を取得** を明示的にオンにした場合のみ、対象ページへ1回接続してプレビュー画像を `.whiteboard` ファイル内に保存します。
